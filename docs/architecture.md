# 아키텍처 / Architecture

**장문의 원문 → LLM-free Semantic Compiler → SemanticDocument → CPU Embeddings → SemanticRepository → Source Recovery → LLM-ready Context**

**Long-form source → LLM-free Semantic Compiler → SemanticDocument → CPU Embeddings → SemanticRepository → Source Recovery → LLM-ready Context**

핵심 원칙은 임베딩이 의미를 *찾고*, 구조화 필드가 원문이 실제로 *무엇을 말했는지* 보존하는 것입니다.

The key principle is that embeddings help *find* related meaning, while structured fields preserve *what the source actually says*.
